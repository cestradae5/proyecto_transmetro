# Card activity: turnstile passes and recharges per card (admin-web)

Branch `feat/card-activity` (based on `feat/bus-passenger-report`). Step 2 of the order agreed in `parada-ridership.md` L2: a staff view of every card's turnstile passes and recharges. Real QPayPro is step 3 (needs sandbox credentials); this view already distinguishes simulated from QPayPro payments and shows any payment state.

## Specs
- S1 (user, verbatim): "¿En la parte de admin-web existe alguna vista para ver las entradas y salida y el recargo de saldos por tarjetas (sobre esta parte ya deberiamos de tener habilitrado la parte de qpaypro)?" Answer: no view existed; the landing "Recarga" card navigated nowhere. User: "continua".
- S2 Access: every route needs a Bearer token and `RECARGAS_REPORTES_CONSULTAR` (seeded for `ADMINISTRADOR_SISTEMA` and `OPERADOR_CENTRAL`); no token -> 401, other roles -> 403. Read-only: no mutation routes.
- S3 Card list: `GET /cards?search=&page=` -> `{ total, page, pageSize, items: [{ numeroTarjeta, saldo, estadoTarjeta }] }`, ordered by number, `pageSize` 20; `search` (optional, trimmed, max 50 chars) matches part of the number, case-insensitive; `page` integer >= 1 (default 1). Invalid `page` or `search` -> 400.
- S4 Card activity: `GET /cards/:numeroTarjeta/activity` -> `{ tarjeta: { numeroTarjeta, saldo, estadoTarjeta }, pasadas, recargas }`. Unknown card -> 404 "La tarjeta no existe.".
  - `pasadas`: turnstile events of the card, newest first, max 100: `{ idEvento, tipo: "ENTRADA" | "SALIDA", montoCobrado, parada: { idParada, nombreParada, esEstacion }, fecha }`.
  - `recargas`: payment transactions of the card (`tbl_transaccion_pago`), newest first, max 100: `{ idTransaccion, referencia, monto, estadoPago, origen: "SIMULADA" | "QPAYPRO", numeroComprobante | null, fecha }`. `origen` is `QPAYPRO` when the transaction has a QPayPro id; `numeroComprobante` comes from its recharge receipt (null while not approved).
- S5 admin-web: the landing "Recarga" card navigates to `/recharges` (guarded by the `recharge_reporting` module). The page "Tarjetas" lists cards (Número, Estado, Saldo `Q12.50`) with a debounced search box ("Buscar por número") and pagination; empty list -> "No hay tarjetas que coincidan.". Selecting a card shows its number, state and balance and two tables: "Pasadas por talanquera" (Fecha, Tipo "Entrada"/"Salida", Parada with "(estación)" when it is one, Cobro) and "Recargas" (Fecha, Monto, Estado, Origen "Simulada"/"QPayPro", Comprobante or "—"); empty tables say "Sin pasadas registradas." / "Sin recargas registradas.". API errors show a message.
