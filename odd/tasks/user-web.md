# User web: card balance, simulated recharge, turnstile simulator

Branch `feat/user-web` (based on `feat/ridership-capacity`). Step 2 of 3 (Engram 2066): a citizen SPA `apps/user-web` deployed as a second Render Static Site against the same API. Real QPayPro stays for step 3.

## Specs
- S1 (user, verbatim): "tenia en mente crear un spa apra abonar saldo a la tarjeta del usuario, y talvez ahi hacer un boton de dev simualndo el uso de la talanquera, ese envio llegaria al servidor, sin autenticacion solo con el nuemro de la tarjeta y el saldo actual que tiene y desde que estacion lo esta haciendo". Balance is never sent by the client (ridership decision): the turnstile body stays `{ numeroTarjeta, idEstacion, tipo }`.
- S2 Identity (user choice: "Solo número de tarjeta (Recomendado)"): no citizen login; the card number identifies the card.
- S3 Public card lookup: `GET /citizen/cards/:numeroTarjeta` (no auth) -> 200 `{ numeroTarjeta, saldo, estadoTarjeta }` (`saldo` number, GTQ). Unknown card -> 404 "La tarjeta no existe.".
- S4 Public stations: `GET /citizen/stations` (no auth) -> 200 `[{ idEstacion, nombreEstacion }]`, only `estado_estacion = 'ACTIVA'`, by name.
- S5 Simulated recharge: `POST /citizen/cards/:numeroTarjeta/recharges` (no auth) `{ monto, referencia }`. Answers 404 unless env `RECHARGE_SIMULATOR_ENABLED` is exactly `true`. `monto`: number with at most 2 decimals, `1.00 <= monto <= 500.00`; `referencia`: client-generated id, 8-100 chars `[A-Za-z0-9-]`. In one transaction: one `tbl_transaccion_pago` (`APROBADA`, `referencia_pago = referencia`, `GTQ`, `fecha_confirmacion` now, no QPayPro id), one `tbl_recarga`, one `tbl_comprobante` (`numero_comprobante` `SIM-<idRecarga>`), and `saldo += monto`. -> 201 `{ idRecarga, numeroComprobante, monto, saldo, fechaRecarga, repetida: false }`. Card not `ACTIVA` -> 409; unknown card -> 404; invalid body -> 400. Every rejection changes nothing.
- S6 Recharge retry: the same `referencia` for the same card returns the original recharge (200, `repetida: true`, current `saldo`) without charging again; the same `referencia` used by another card or another amount -> 409, nothing changes.
- S7 Turnstile retry (verifier finding 1, user: "continuemos"): `TurnstilePassDto` gains optional `idempotencyKey` (8-64 chars `[A-Za-z0-9-]`), stored in `tbl_evento_talanquera.clave_idempotencia` (UNIQUE, nullable). The same key with the same card, station and type returns the original event (`repetido: true`, `montoCobrado` as stored, current `saldo` and station, `alertaGenerada: false`) without a new event, charge or alert; same key with a different card/station/type -> 409. Without the key, behavior is unchanged. Every response gains `repetido` (false for new passes).
- S8 SPA card screen: enter a card number -> shows number, state and balance (`Q12.50`); unknown card shows "La tarjeta no existe."; empty input is not sent. "Consultar otra tarjeta" goes back.
- S9 SPA recharge: amount input (1-500, 2 decimals) -> confirm -> shows "Recarga exitosa", the comprobante and the new balance. The button is disabled while sending; one `referencia` per confirmed attempt (`crypto.randomUUID()`), reused if the same attempt is retried after a network error. API errors are shown with their message. If the API answers 404 for the recharge route, the screen says "Las recargas no están disponibles." The UI states the recharge is simulated (no real payment).
- S10 SPA turnstile simulator: only rendered when `VITE_TURNSTILE_SIMULATOR=true`. Pick a station (from S4) and press "Entrar" or "Salir": sends the S1 body plus an `idempotencyKey` (fresh per pass; repeating the same station and type right after a network error reuses it, per S7 — L12) and header `X-Turnstile-Key: VITE_TURNSTILE_API_KEY`; buttons disabled while sending. Shows charge, new balance, people in the station and, when `alertaGenerada`, "Se generó una alerta de capacidad". Updates the shown balance. Documented as a development tool: the key ships in the bundle.
- S11 Deploy: `apps/user-web` builds with `npm run build` to `dist/`; README explains local run (port 5174) and the Render Static Site (build command, publish dir, env vars `VITE_API_BASE_URL`, `VITE_TURNSTILE_SIMULATOR`, `VITE_TURNSTILE_API_KEY`), and the API env `RECHARGE_SIMULATOR_ENABLED`. UI copy in neutral Spanish (as admin-web), code in English.
